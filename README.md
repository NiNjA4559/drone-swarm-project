# Drone Swarm Project

### 1. Generate testcases using `cd ./generator && node . && cd ../`.

### 2. Compile using `mingw32-make build`.

### 3. Run the simulation using `mingw-32make run`. This also stores the state of the system at each tick in `/visualisation/simulation.js`.
